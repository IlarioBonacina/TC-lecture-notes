20.1 A PDA simulator

Below you have a simple PDA simulator, with a couple of examples already implemented.

Warning

The simulator is experimental and use Pyodide to run the simulation. It might not run properly on small screens such as smartphones. Please report any bug.

To use it, write the transitions of a (nondeterministic) pushdown automaton, enter an input word and press Run or Step. Every step advances all computations in parallel: each card below is one configuration (state, input position, stack), and the diagram highlights the states that are currently active.

Format: state input pop -> new_state push. In state, read input and pop pop from the top of the stack, go to new_state and push the string push (its leftmost symbol ends up on top). Use ε (type eps) for "read nothing", "don't touch the stack" or "push nothing". # starts a comment. The initial stack is written top first. All computations are explored in parallel, and a configuration that was already visited is not explored again.

Drag the states to rearrange the diagram.
