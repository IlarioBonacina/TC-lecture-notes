Exercise 35.1 (Brute force for triangles)  

Consider the problem \mathtt{TRIANGLEFREE}: given an undirected graph G, encoded as an adjacency matrix, decide whether G contains no triangle. A triangle is a set of three vertices u, v, w that are pairwise connected: \{u,v\}, \{v,w\}, \{w,u\} \in E(G). Let n = |V(G)|. What can we say about the algorithm that considers every set of three vertices and, for each one, checks whether they form a triangle?

A. It is \mathcal{O}(3n) = \mathcal{O}(n).

The algorithm looks at every set of three vertices, and there are \binom{n}{3} = \frac{n(n-1)(n-2)}{6} of them. The 3 is the size of each set, not a factor in front of n. Since \binom{n}{3} grows like n^3/6, the algorithm is \mathcal{O}(n^3), not \mathcal{O}(n).

B. It is \mathcal{O}(n^3), but it is not clear how to decide \mathtt{TRIANGLEFREE} in linear time.

There are \binom{n}{3} = \mathcal{O}(n^3) sets of three vertices, and each one is checked with three lookups in the adjacency matrix, so the algorithm runs in time \mathcal{O}(n^3). The input is an n \times n matrix, so its size is N = n^2, and linear time means \mathcal{O}(n^2). The best known algorithms reduce triangle detection to matrix multiplication and take about \mathcal{O}(n^{2.37}). Whether time \mathcal{O}(n^2) is possible is an open problem.

C. It is \mathcal{O}(3^n), and it is not clear how to decide \mathtt{TRIANGLEFREE} in polynomial time.

The number of sets of three vertices is \binom{n}{3} \leqslant n^3, which is polynomial in n, not exponential. Exponentially many subsets appear only when the size of the subsets is part of the input, as in \mathtt{CLIQUE}. Here the size is fixed at 3, so the brute-force algorithm already runs in polynomial time.

D. None of the other answers is correct.

One of the other answers is correct. The algorithm checks \binom{n}{3} = \mathcal{O}(n^3) triples, each in constant time. Since the input has size n^2, linear time would mean \mathcal{O}(n^2), and no such algorithm is known.

Exercise 35.2 (From 3 colors to k colors)  

We want to show that 3\text{-}\mathtt{COLORING} \leqslant_m^p k\text{-}\mathtt{COLORING} for every k \geqslant 4. Which of the following ideas leads to a correct reduction? Given an undirected graph G as input, we build a graph G' consisting of

A. the disjoint union of G and a k-clique.

The k-clique can be colored with k colors on its own, and since it is not connected to G, it puts no constraint on G. So G' is k-colorable if and only if G is k-colorable, which is a different question from whether G is 3-colorable. For example, take k = 4 and G = K_4. Then G is not 3-colorable, but G' is 4-colorable, so the reduction maps a no-instance to a yes-instance.

B. the union of G and a k-clique, plus all possible edges between the copy of G and the k-clique.

The k-clique uses all k colors, and every vertex of G is adjacent to all of them. So, as soon as G has a vertex, G' contains a (k+1)-clique and is never k-colorable. The reduction maps every graph, including the 3-colorable ones, to a no-instance.

C. the disjoint union of G and a (k-3)-clique.

Since the (k-3)-clique is not connected to G, it does not restrict the colors available to G. So G' is k-colorable if and only if G is k-colorable, not 3-colorable. The same counterexample as before works: G = K_4 with k = 4 is not 3-colorable, but G' is 4-colorable.

D. the union of G and a (k-3)-clique, plus all possible edges between the copy of G and the (k-3)-clique.

The (k-3)-clique needs k-3 different colors, and every vertex of G is adjacent to all of them. So, in a k-coloring of G', the vertices of G can only use the 3 remaining colors, which gives a 3-coloring of G. Conversely, a 3-coloring of G together with k-3 new colors for the clique is a k-coloring of G'. Hence G \in 3\text{-}\mathtt{COLORING} \iff G' \in k\text{-}\mathtt{COLORING}, and G' can be built in polynomial time.

Exercise 35.3 (Equivalence classes in \mathbf{P})  

We say that A\equiv_m^p B if and only if A\leqslant_m^p and B\leqslant_m^p A. This gives an equivalence relation, and hence it divides the class \mathbf{P} into equivalence classes. How many?

A. 1

Not every language in \mathbf{P} is equivalent to every other. The language \emptyset only reduces to itself: if L \leqslant_m^p \emptyset, then w \in L \iff f(w) \in \emptyset, so L = \emptyset. In the same way, only \Sigma^* reduces to \Sigma^*. So \emptyset and \Sigma^* are each alone in their class.

B. 2

The two trivial languages \emptyset and \Sigma^* are not equivalent to each other, nor to any other language: the only language that reduces to \emptyset is \emptyset itself, and the only one that reduces to \Sigma^* is \Sigma^*. Together with the class of all the remaining languages in \mathbf{P}, this gives more than two classes.

C. 3

The classes are \{\emptyset\}, \{\Sigma^*\} and all the other languages in \mathbf{P}. If L_1, L_2 \in \mathbf{P} and L_2 \neq \emptyset, \Sigma^*, then L_1 \leqslant_m^p L_2: fix a word y \in L_2 and a word n \notin L_2, and let f(w) = y if w \in L_1 and f(w) = n otherwise. This f is computable in polynomial time, because the reduction can decide L_1 by itself. So all nontrivial languages in \mathbf{P} are equivalent. On the other hand, only \emptyset reduces to \emptyset and only \Sigma^* reduces to \Sigma^*.

D. \infty

Inside \mathbf{P}, polynomial-time reductions are too powerful to tell languages apart: a reduction can simply solve the instance and output a fixed yes-instance or a fixed no-instance. So all languages in \mathbf{P} other than \emptyset and \Sigma^* are equivalent, and there are only finitely many classes. (Finer distinctions inside \mathbf{P} need weaker reductions, for example reductions computable in logarithmic space.)

Exercise 35.4 (Isomorphic graphs)  

Which of the following graphs are isomorphic?

A. (a) and (b)

In graph (b), the vertices 6, 8 and 10 form a triangle. Graph (a) is the Petersen graph, which has no triangles (it has no cycles of length less than 5). An isomorphism maps triangles to triangles, so (a) and (b) are not isomorphic. Also, (b) has two vertices of degree 4, while every vertex of (a) has degree 3.

B. (c) and (d)

Graph (d) contains cycles of length 4, for example 1, 2, 7, 6. Graph (c) has no cycle of length less than 5. An isomorphism maps 4-cycles to 4-cycles, so (c) and (d) are not isomorphic, even though both have 10 vertices of degree 3 and 15 edges.

C. (a) and (c)

Both are drawings of the Petersen graph. The map 1 \mapsto 1,\ 2 \mapsto 2,\ 3 \mapsto 3,\ 4 \mapsto 4,\ 5 \mapsto 10,\ 6 \mapsto 9,\ 7 \mapsto 8,\ 8 \mapsto 7,\ 9 \mapsto 6,\ 10 \mapsto 5 sends every edge of (a) to an edge of (c), and both graphs have 15 edges, so it is an isomorphism. Note how different the two drawings look. In general, no polynomial-time algorithm for graph isomorphism is known, although it is not believed to be \mathbf{NP}-complete.

D. (b) and (d)

Graph (b) has a triangle (6, 8, 10), but graph (d) has none, so they are not isomorphic. Counting degrees also works: (b) has two vertices of degree 4, and every vertex of (d) has degree 3.

Exercise 35.5 (Subgraph isomorphism)  

The subgraph isomorphism problem, \mathtt{SGI}, is the following:

Given two graphs G and H, decide whether G contains a subgraph that is isomorphic to H.

What can we say about this problem?

A. It is equivalent to \mathtt{GI}.

\mathtt{GI} reduces to \mathtt{SGI}: two graphs with the same number of vertices and edges are isomorphic if and only if one is isomorphic to a subgraph of the other. But \mathtt{SGI} is \mathbf{NP}-complete, so if it reduced to \mathtt{GI}, then \mathtt{GI} would be \mathbf{NP}-complete too, which is believed to be false. So we cannot claim that the two problems are equivalent.

B. It is in \mathbf{P}.

\mathtt{SGI} is \mathbf{NP}-complete (see the correct answer), so it is in \mathbf{P} only if \mathbf{P}= \mathbf{NP}. We cannot claim this.

C. It is \mathbf{NP}-complete.

\mathtt{SGI} \in \mathbf{NP}: a certificate is the subgraph of G together with the isomorphism, and both can be checked in polynomial time. It is \mathbf{NP}-hard because \mathtt{CLIQUE}\leqslant_m^p \mathtt{SGI}: map \langle G, k \rangle to \langle G, K_k \rangle, where K_k is the complete graph on k vertices. A subgraph of G isomorphic to K_k is exactly a k-clique in G. Unlike \mathtt{GI}, which is a candidate \mathbf{NP}-intermediate problem, \mathtt{SGI} is as hard as any problem in \mathbf{NP}.

D. None of the above.

One of the answers is correct: \mathtt{SGI} is in \mathbf{NP}, and \mathtt{CLIQUE} reduces to it by taking H = K_k, so it is \mathbf{NP}-complete.

Exercise 35.6 (Minimal formulas)  

Two Boolean formulas F and F' over n variables are equivalent if F(\alpha) = F'(\alpha) for every \alpha \in \{0,1\}^n. We define the problem \mathtt{MIN}\text{-}\mathtt{FRM} = \{\, \langle F \rangle : F \text{ is a Boolean formula with no smaller equivalent formula} \,\}. Which class can we guarantee that \mathtt{MIN}\text{-}\mathtt{FRM} belongs to?

A. \mathbf{NP}

To show that F is minimal, it is not enough to exhibit one object: we must rule out every smaller formula. A short certificate for “no smaller formula is equivalent” is not known. What is easy to certify is the opposite, that F is not minimal, and even that needs two quantifiers (see the correct answer).

B. \mathbf{co}\mathbf{NP}

The statement “for every smaller formula F', F' is not equivalent to F” starts with a universal quantifier, but “not equivalent” is itself an existential statement: there is an \alpha with F(\alpha) \neq F'(\alpha). So the definition has the form \forall F'\, \exists \alpha, with two quantifiers, and a single \forall followed by a polynomial-time check is not known to suffice.

C. \Sigma_2^p

It is the complement of \mathtt{MIN}\text{-}\mathtt{FRM} that is in \Sigma_2^p: F is not minimal if and only if \exists F'\, \forall \alpha\, \big[\, |F'| < |F| \text{ and } F'(\alpha) = F(\alpha) \,\big]. \mathtt{MIN}\text{-}\mathtt{FRM} itself has the form \forall\, \exists, and it is not known to be in \Sigma_2^p.

D. \Pi_2^p

By definition, \langle F \rangle \in \mathtt{MIN}\text{-}\mathtt{FRM} \iff \forall F'\ \exists \alpha\ \big[\, |F'| < |F| \Rightarrow F'(\alpha) \neq F(\alpha) \,\big]. Both F' and \alpha have length at most |\langle F \rangle|, and the condition in brackets can be checked in polynomial time by evaluating both formulas. This is a \forall\, \exists statement followed by a polynomial-time check, so \mathtt{MIN}\text{-}\mathtt{FRM} \in \Pi_2^p.

Exercise 35.7 (Exact vertex cover (Partial exam 2, 05/06/2026))  

A vertex cover of a graph G is a subset of its vertices that includes at least one endpoint of every edge of G. Consider the \mathtt{EXACT\ VERTEX\ COVER} problem: “given a graph G and an integer k, is the minimum size of a vertex cover of G exactly k?”

With the theory seen in this course, you can prove that three of the following four statements are true. Which is the remaining one?

A. \mathtt{EXACT\ VERTEX\ COVER} \in \Sigma_1^p \cup \Pi_1^p.

This is the statement we cannot prove. “The minimum is exactly k” says two things: there is a vertex cover of size k, which is an \mathbf{NP} condition, and there is no vertex cover of size k-1, which is a \mathbf{co}\mathbf{NP} condition. So the problem is the intersection of a language in \mathbf{NP}= \Sigma_1^p and a language in \mathbf{co}\mathbf{NP}= \Pi_1^p. Nothing seen in the course shows that it is in \mathbf{NP} or in \mathbf{co}\mathbf{NP}, and this is believed to be false.

B. The complement of \mathtt{EXACT\ VERTEX\ COVER} belongs to \Pi_2^p.

This statement is true. \mathtt{EXACT\ VERTEX\ COVER} \in \Sigma_2^p: \langle G, k \rangle \in \mathtt{EXACT\ VERTEX\ COVER} \iff \exists C\ \forall C'\ \big[\, C \text{ is a vertex cover of size } k, \text{ and } C' \text{ is not a vertex cover of size } k-1 \,\big], and both conditions can be checked in polynomial time. Taking complements swaps \Sigma_2^p and \Pi_2^p, so the complement is in \Pi_2^p.

C. \mathtt{EXACT\ VERTEX\ COVER} \in \Sigma_3^p.

This statement is true. As shown in the previous option, \mathtt{EXACT\ VERTEX\ COVER} \in \Sigma_2^p, and \Sigma_2^p \subseteq \Sigma_3^p, because a verifier can ignore an extra certificate.

D. If \mathtt{EXACT\ VERTEX\ COVER} \notin \Sigma_1^p, then \Sigma_1^p \neq \Pi_1^p.

This statement is true. Consider the contrapositive: if \Sigma_1^p = \Pi_1^p, then the polynomial hierarchy collapses to \Sigma_1^p, so \Sigma_2^p = \Sigma_1^p. Since \mathtt{EXACT\ VERTEX\ COVER} \in \Sigma_2^p, it would then be in \Sigma_1^p.

Exercise 35.8 (Coloring planar graphs (Partial exam 2, 05/06/2026))  

Most computer scientists believe that \mathbf{P}\neq \mathbf{NP}. Under this belief, one of the following statements is false. Which one?

Recall that all planar graphs are 4-colorable, and that a 4-coloring can be computed in polynomial time. Moreover, given a planar graph G, deciding whether G is 3-colorable is known to be \mathbf{NP}-hard.

A. There is some planar graph which is not 3-colorable.

This statement is true. The complete graph K_4 is planar (draw a triangle with one vertex in the middle, joined to the three corners), and it is not 3-colorable, because its four vertices are pairwise adjacent and need four different colors.

B. Given a graph G and a 4-coloring of it, deciding whether G is 3-colorable is a problem in \mathbf{P}.

This statement is false under the assumption \mathbf{P}\neq \mathbf{NP}. The last option shows that this problem is \mathbf{NP}-hard. An \mathbf{NP}-hard problem in \mathbf{P} would give \mathbf{P}= \mathbf{NP}. Knowing a 4-coloring does not help to find a 3-coloring.

C. Given a graph G with n vertices, deciding whether G is n-colorable is a problem in \mathbf{P}.

This statement is true, and the problem is trivial: every graph with n vertices is n-colorable, by giving each vertex a different color. So the algorithm always answers yes. This does not contradict the hardness of 3\text{-}\mathtt{COLORING}, because here the number of colors grows with the graph.

D. Given a graph G and a 4-coloring of it, deciding whether G is 3-colorable is \mathbf{NP}-hard.

This statement is true. We reduce 3-colorability of planar graphs, which is \mathbf{NP}-hard, to this problem. Map a planar graph G to the pair (G, c), where c is a 4-coloring of G. Since G is planar, c exists and can be computed in polynomial time. Clearly, G is 3-colorable if and only if (G, c) is a yes-instance.

Exercise 35.9 (A dichotomy for \mathbf{NP} (Partial exam 2, 05/06/2026))  

Suppose that every problem in \mathbf{NP} is either in \mathbf{P} or \mathbf{NP}-complete. Which of the following statements is true?

A. \mathbf{P}= \mathbf{NP} and \mathbf{NP}= \mathbf{EXP}

The two equalities together would give \mathbf{P}= \mathbf{EXP}. This contradicts the time hierarchy theorem, which shows that \mathbf{P}\neq \mathbf{EXP}, whatever we assume about \mathbf{NP}.

B. \mathbf{P}\neq \mathbf{NP} and \mathbf{NP}= \mathbf{EXP}

By Ladner’s theorem, if \mathbf{P}\neq \mathbf{NP}, then there is a problem in \mathbf{NP} that is neither in \mathbf{P} nor \mathbf{NP}-complete. This contradicts the assumption, so \mathbf{P}\neq \mathbf{NP} is impossible here.

C. \mathbf{P}= \mathbf{NP} and \mathbf{NP}\neq \mathbf{EXP}

If we had \mathbf{P}\neq \mathbf{NP}, Ladner’s theorem would give an \mathbf{NP}-intermediate problem, contradicting the assumption. So \mathbf{P}= \mathbf{NP}. Then \mathbf{NP}= \mathbf{P}\neq \mathbf{EXP} by the time hierarchy theorem. In general, \mathbf{P}\subseteq \mathbf{NP}\subseteq \mathbf{EXP} and at least one inclusion is strict. Here the assumption forces the first inclusion to be an equality, so the second must be strict.

D. \mathbf{P}\neq \mathbf{NP} and \mathbf{NP}\neq \mathbf{EXP}

By Ladner’s theorem, \mathbf{P}\neq \mathbf{NP} would imply the existence of an \mathbf{NP}-intermediate problem, contradicting the assumption that every problem in \mathbf{NP} is in \mathbf{P} or \mathbf{NP}-complete. So \mathbf{P}= \mathbf{NP}, and this option is false.
