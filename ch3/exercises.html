Exercise 28.1 (A complement of a union)  

Let A, B and C be languages such that A \in \mathbf{RE}\setminus \mathbf{R} and A = \overline{B \cup C}. Which of the following options for B and C is not possible?

A. B \in \mathbf{RE} and C \in \mathbf{RE}

\mathbf{RE} is closed under union, so B \cup C \in \mathbf{RE}. But B \cup C = \overline{A}, so \overline{A} \in \mathbf{RE}, which means A \in \mathbf{co}\mathbf{RE}. Together with A \in \mathbf{RE}, this gives A \in \mathbf{RE}\cap \mathbf{co}\mathbf{RE}= \mathbf{R}, contradicting A \notin \mathbf{R}. So this option is impossible.

B. B \in \mathbf{RE} or C \in \mathbf{RE}

This is possible. Take B = \emptyset and C = \overline{A}. Then \overline{B \cup C} = A, and B = \emptyset \in \mathbf{RE}. Only one of the two languages has to be in \mathbf{RE}, so the argument for the correct answer does not apply.

C. B \in \mathbf{co}\mathbf{RE} or C \in \mathbf{co}\mathbf{RE}

This is possible. Since A \in \mathbf{RE}, its complement \overline{A} is in \mathbf{co}\mathbf{RE}. Take B = \overline{A} and C = \emptyset. Then \overline{B \cup C} = A, and B \in \mathbf{co}\mathbf{RE}.

D. B \in \mathbf{co}\mathbf{RE} and C \in \mathbf{co}\mathbf{RE}

This is possible. Take again B = \overline{A} \in \mathbf{co}\mathbf{RE} and C = \emptyset, which is in \mathbf{co}\mathbf{RE} because it is decidable. Then \overline{B \cup C} = A. This is consistent: \mathbf{co}\mathbf{RE} is closed under union, and indeed B \cup C = \overline{A} \in \mathbf{co}\mathbf{RE}.

Exercise 28.2 (Twin primes)  

Let L = \{\, n \in \mathbb{N} :\exists p \geqslant n \text{ such that } p \text{ and } p+2 \text{ are both prime} \,\}. Which is the strongest statement you can guarantee for sure to be true?

A. L \in \mathbf{co}\mathbf{RE}

This is true, but it follows from a stronger statement (see the correct answer). Note that it is not obvious directly: to reject n, we would have to be sure that there are no twin primes beyond n, and no search can confirm that. The point is that L is decidable, and every decidable language is in \mathbf{co}\mathbf{RE}. The best answer is the strongest one we can guarantee.

B. L \in \mathbf{RE}

This is true: on input n, search p = n, n+1, n+2, \dots and accept when p and p+2 are both prime. If n \in L, the search ends. But this only shows L \in \mathbf{RE}, and we can say more: L is decidable (see the correct answer). The best answer is the strongest one we can guarantee.

C. L \in \mathbf{R}

L is closed downwards: if n \in L and m \leqslant n, then m \in L. So there are only two possibilities. If there are infinitely many twin primes, then L = \mathbb{N}. Otherwise, let p_0 be the largest prime such that p_0 + 2 is also prime, and then L = \{0, 1, \dots, p_0\}. In both cases, L is decidable: \mathbb{N} is decided by a machine that always accepts, and \{0, \dots, p_0\} by a machine that compares n with the constant p_0. We do not know which of these machines decides L, because the twin prime conjecture is open, but we know that one of them does. Decidability asks for the existence of a decider, not for us to know which one it is.

D. L \notin \mathbf{RE}\cup \mathbf{co}\mathbf{RE}

This is false. As explained in the correct answer, L is either \mathbb{N} or a finite set, and in both cases L \in \mathbf{R}\subseteq \mathbf{RE}\cap \mathbf{co}\mathbf{RE}.

Exercise 28.3 (Which statement is false?)  

Which of the following statements about languages A, B \subseteq \{0,1\}^* is false?

A. If A = \mathcal{L}(M) where M is a Turing machine that does not halt on 010, then A \in \mathbf{RE}\setminus \mathbf{R}.

This statement is false. The fact that one particular machine M for A does not halt does not mean that every machine for A fails to halt. For example, let M accept every word except 010, and loop forever on 010. Then A = \mathcal{L}(M) = \{0,1\}^* \setminus \{010\}. This language is decidable: another machine can check whether its input is 010 and reject it, and accept everything else. So A \in \mathbf{R}. Decidability is a property of the language, not of one machine that recognizes it.

B. If A \notin \mathbf{R}, then A \cup \{0101\} \notin \mathbf{R}.

This statement is true. Suppose A \cup \{0101\} were decidable, with decider D. Then A would also be decidable. If 0101 \in A, then A = A \cup \{0101\}. If 0101 \notin A, then A = (A \cup \{0101\}) \setminus \{0101\}, which is decided by running D and rejecting 0101. We may not know which case holds, but in both cases a decider for A exists, contradicting A \notin \mathbf{R}. Changing a language on finitely many words never affects decidability.

C. If A \notin \mathbf{R} and B is finite, then A \cup B \notin \mathbf{R}.

This statement is true. It is the previous statement with \{0101\} replaced by any finite set. If A \cup B were decidable, then A = (A \cup B) \setminus (B \setminus A) would be decidable too, because B \setminus A is finite and a decider can store the finitely many words of B \setminus A and reject them.

D. If A \in \mathbf{RE}, there are infinitely many Turing machines that recognize A.

This statement is true. If M recognizes A, we can add any number of new states that are never reached, and we obtain infinitely many different machines that all recognize A. This is the same padding trick that gives every machine infinitely many encodings, which we use in the proof of the time hierarchy theorem.

Exercise 28.4 (Right-moving Turing machines (Partial exam 2, 05/06/2026))  

A Turing machine is called right-moving if its head can never move to the left or stay in the same position (that is, it can only move to the right). What is the class of languages accepted by right-moving Turing machines?

A. The languages in \mathbf{P}.

\mathbf{P} contains non-regular languages such as \{0^n 1^n :n \geqslant 0\}, which a right-moving TM cannot accept. Such a machine reads each input symbol exactly once, from left to right, and can never come back to anything it has written. So the only memory it has is its finite set of states, and it cannot count the 0s in order to compare them with the 1s.

B. The context-free languages.

A right-moving TM cannot even accept the context-free language \{0^n 1^n :n \geqslant 0\}. Unlike a pushdown automaton, it has no stack: everything it writes is left behind, to the left of the head, and it can never read it again. Its only memory is its finite set of states.

C. The recursive languages.

Being able to move left is essential for a TM to use its tape as memory. A right-moving TM reads each input symbol once and never revisits a cell, so it behaves like a finite automaton. It cannot accept non-regular decidable languages such as \{0^n 1^n :n \geqslant 0\}.

D. The regular languages.

A right-moving TM scans its input from left to right, one symbol per step, and whatever it writes lands in cells it will never visit again. So its behaviour depends only on its current state and the current input symbol, exactly like a DFA. After the input, it only reads blanks, and its behaviour from then on depends only on the state in which it left the input, so a DFA can tell in advance whether it will eventually accept. Conversely, every DFA is a right-moving TM. Hence right-moving TMs accept exactly the regular languages.

Exercise 28.5 (Where a machine does not halt (Partial exam 2, 05/06/2026))  

Let M be a Turing machine, let A = \mathcal{L}(M) be the language recognized by M, and let B = \{w :M(w)\uparrow\} be the set of words on which M does not halt. Which of the following statements is false for some M?

Recall that \mathbf{R} is the class of all decidable languages, and that a set S is cofinite if \overline{S} is finite.

A. If B is cofinite, then A \in \mathbf{R}.

This statement is always true. M can only accept words on which it halts, so A \subseteq \overline{B}. If B is cofinite, then \overline{B} is finite, so A is finite, and every finite language is decidable.

B. If B is finite, then A \in \mathbf{R}.

This statement is always true. If B is finite, a decider for A can store the finitely many words of B. On input w, it rejects if w \in B, because M does not halt on w and so does not accept it. Otherwise, it simulates M on w, which is guaranteed to halt, and gives the same answer.

C. A \in \mathbf{RE} independently of B.

This statement is always true. By definition, A = \mathcal{L}(M) is recognized by the Turing machine M, so A \in \mathbf{RE}, whatever B is.

D. If B is infinite, then A \in \mathbf{R}.

This statement fails for some M. Let K = \{p :M_p(p)\downarrow\}. Then K \in \mathbf{RE}, so K = \mathcal{L}(M) for some TM M, and we can take A = K. We know that K \notin \mathbf{R}. Moreover, B is infinite: there are infinitely many programs p with M_p(p)\uparrow, and on each of them M does not halt. So B is infinite but A \notin \mathbf{R}.

Exercise 28.6 (Programs with finite image (Partial exam 2, 05/06/2026))  

Consider the language L = \{\, p :\mathrm{Im}(\varphi_p) \text{ is finite} \,\}, where \varphi_p is the function computed by the program p. Which of the following is true?

A. L \in \mathbf{co}\mathbf{RE}\setminus \mathbf{R}

L is not in \mathbf{co}\mathbf{RE}, because K \leqslant_m L. Given x, build a program p_x that, on input y, outputs 1 if M_x(x) halts within |y| steps, and outputs y otherwise. If M_x(x)\downarrow in t steps, then p_x outputs 1 on all inputs of length at least t, so its image is finite. If M_x(x)\uparrow, then p_x computes the identity, whose image is infinite. So x \in K \iff p_x \in L, and since K \notin \mathbf{co}\mathbf{RE}, also L \notin \mathbf{co}\mathbf{RE}.

B. L \in \mathbf{R}

L is not decidable. By Rice’s theorem, “the image of \varphi_p is finite” is a nontrivial semantic property, so L \notin \mathbf{R}. In fact, L is not even in \mathbf{RE}\cup \mathbf{co}\mathbf{RE} (see the correct answer).

C. L \in \mathbf{RE}\setminus \mathbf{R}

L is not in \mathbf{RE}, because \overline{K} \leqslant_m L. Given x, build a program q_x that, on input y, first runs M_x(x) and then outputs y. If M_x(x)\downarrow, then q_x computes the identity, whose image is infinite. If M_x(x)\uparrow, then q_x never outputs anything, so its image is empty, and hence finite. So x \in \overline{K} \iff q_x \in L, and since \overline{K} \notin \mathbf{RE}, also L \notin \mathbf{RE}.

D. L \notin \mathbf{RE}\cup \mathbf{co}\mathbf{RE}

We give two reductions.

  • \overline{K} \leqslant_m L: map x to a program that runs M_x(x) and then outputs its input y. Its image is empty if M_x(x)\uparrow and infinite if M_x(x)\downarrow. Hence L \notin \mathbf{RE}.
  • K \leqslant_m L: map x to a program that, on input y, outputs 1 if M_x(x) halts within |y| steps, and outputs y otherwise. Its image is finite if M_x(x)\downarrow and infinite if M_x(x)\uparrow. Hence L \notin \mathbf{co}\mathbf{RE}.

So L is neither in \mathbf{RE} nor in \mathbf{co}\mathbf{RE}.

Exercise 28.7 (Many-one reductions and complexity classes (Partial exam 2, 05/06/2026))  

Which of the following statements is correct?

Recall that \mathbf{P} is the class of languages decidable in polynomial time, and that A \leqslant_m B means that there is a many-one reduction from A to B, not necessarily computable in polynomial time.

A. If B \in \mathbf{P} and A \leqslant_m B, then A \in \mathbf{P}.

This statement is false, because the reduction may take much more than polynomial time. Take any language A \in \mathbf{EXP}\setminus \mathbf{P}, which exists by the time hierarchy theorem, and let B = \{1\}. The reduction decides A by itself, in exponential time, and outputs 1 if w \in A and 0 otherwise. So A \leqslant_m B and B \in \mathbf{P}, but A \notin \mathbf{P}. This property only holds for polynomial-time reductions.

B. If A \in \mathbf{R}, there is a language B \in \mathbf{P} such that A \leqslant_m B.

This statement is true. Take B = \{1\}, which is in \mathbf{P}. The reduction f decides A, which is possible because A \in \mathbf{R}, and outputs f(w) = 1 if w \in A and f(w) = 0 otherwise. Then w \in A \iff f(w) \in B, and f is computable (although perhaps very slowly). So, without a time bound on the reduction, every decidable language reduces to a trivial language in \mathbf{P}.

C. If B \in \mathbf{P} and A \leqslant_m B, then A might not belong to \mathbf{R}.

This statement is false. If A \leqslant_m B and B \in \mathbf{R}, then A \in \mathbf{R}: to decide whether w \in A, compute f(w) and decide whether f(w) \in B. Since \mathbf{P}\subseteq \mathbf{R}, every language that reduces to a language in \mathbf{P} is decidable. Equivalently, if A \notin \mathbf{R} and A \leqslant_m B, then B \notin \mathbf{R}.

D. If B \in \mathbf{NP} and A \leqslant_m B, then A \in \mathbf{NP}.

This statement is false, for the same reason as the first option. By the time hierarchy theorem, there is a decidable language A that is not in \mathbf{EXP}, for example one decidable in doubly exponential time. Since \mathbf{NP}\subseteq \mathbf{EXP}, A \notin \mathbf{NP}. But A \leqslant_m \{1\} by the reduction that decides A and outputs 1 or 0, and \{1\} \in \mathbf{P}\subseteq \mathbf{NP}. Closure of \mathbf{NP} under reductions only holds for polynomial-time reductions.
