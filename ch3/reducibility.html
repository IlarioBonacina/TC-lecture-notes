27  Many-One Reductions

% noend hides “end for”; drop it to keep them

In this chapter we see how to prove that many languages are not in \mathbf{R}. Informally, this is done by “reducing” the problem of showing that a language L is in \mathbf{R}, by showing that \mathtt{K} or some other language we already know is not in \mathbf{R} is “easier” than our language L. Formally, this is done uasing the concept of many-one reductions.

Definition 27.1 Given languages A,B\subseteq \Sigma^*, we say tha A is many-one reducible to B, written A\leq_m B, if there is a total computable function f\colon\Sigma^*\to\Sigma^* such that for every x, x\in A\iff f(x)\in B. We say that f is a reduction from A to B.

Recall that a f\colon\Sigma^*\to\Sigma^* is a total computable function s.t. there is a Turing machine M where for every input x\in \Sigma^*, M(x) halts, accepts and has on the tape f(x).

If A\leq_m B, then A is “no harder” than B: to decide whether x\in A, compute f(x) and ask whether f(x)\in B. The following properties follow directly from the definition.

Theorem 27.1  

  1. \leq_m is reflexive and transitive.
  2. A\leq_m B if and only if \overline{A}\leq_m\overline{B}.
  3. If A\leq_m B and B\in\mathbf{R} (resp. \mathbf{RE}, \mathbf{co}\mathbf{RE}, \Sigma^0_k, \Pi^0_k), then A belongs to the same class.

Item 3 is usually used in the contrapositive: to show that B\notin\mathbf{R}, reduce a known undecidable language to B. Note the direction: the known hard language goes on the left.

Example 27.1 Let
\mathtt{E_{DFA}}=\{\langle D\rangle:D \text{ is a DFA and } \mathscr{L}(D)=\emptyset\} and \mathtt{EQ_{DFA}}=\{\langle D_1,D_2\rangle:D_1,D_2 \text{ are DFAs and } \mathscr{L}(D_1)=\mathscr{L}(D_2)\}. We want to use that \mathtt{EQ_{DFA}}\leq_m\mathtt{E_{DFA}}, \mathtt{E_{DFA}}\in \mathbf{R} to conclude that \mathtt{E_{DFA}}\in\mathbf{R}.

\mathtt{E_{DFA}}\in\mathbf{R}. \mathscr{L}(D)=\emptyset exactly when no accepting state of D can be reached from the initial state. A graph search on the transition diagram of D checks this.

The reduction. Map \langle D_1,D_2\rangle to \langle D\rangle, where D is a DFA for the symmetric difference \mathscr{L}(D)=\big(\mathscr{L}(D_1)\setminus \mathscr{L}(D_2)\big)\cup\big(\mathscr{L}(D_2)\setminus \mathscr{L}(D_1)\big). D can be computed with the product construction. Its states are pairs (p,q) of states of D_1 and D_2, and (p,q) is accepting when exactly one of p and q is accepting. Then \begin{align*} \langle D_1,D_2\rangle\in\mathtt{EQ_{DFA}}& \iff \mathscr{L}(D_1)=\mathscr{L}(D_2) \\ &\iff \mathscr{L}(D)=\emptyset \\ &\iff\langle D\rangle\in\mathtt{E_{DFA}}\ . \end{align*} If the input is not a well-formed pair of DFAs, map it to a fixed string that is not in \mathtt{E_{DFA}}. Then \mathtt{EQ_{DFA}}\in\mathbf{R} by Theorem 27.1.

Let’s see now another (more interesting) example.

Example 27.2 Let \mathtt{K}=\{p:M_p(p)\!\downarrow\} and \mathtt{HALT}=\{\langle p,w\rangle:M_p(w)\!\downarrow\}. Then \mathtt{K}\leq_m\mathtt{HALT}, therefore \mathtt{HALT}\notin\mathbf{R}.

Let f(p)=\langle p,p\rangle. The function f is total and computable: it copies its input and applies the pairing function. For every p, p\in \mathtt{K}\iff M_p(p)\!\downarrow\iff\langle p,p\rangle\in\mathtt{HALT}\iff f(p)\in\mathtt{HALT}\ .

In the RACSO page you have several examples of many-one reductions but be aware that not all interesting reductions to \mathtt{K} or \overline{\mathtt{K}} can be written using the language in the RACSO page.

One example of reduction that cannot be done using the languge of RACSO is the following:

Exercise 27.1 Show that L=\{p:\mathrm{dom}(\phi_p)\in \mathbf{R}\}\notin \mathbf{RE}\cup\mathbf{co}\mathbf{RE} producing two reductions \mathtt{K}\leq_m L and \overline{\mathtt{K}}\leq_m L.

What is the smallest level of the arithmetic hierarchy you can show contains L?

27.1 A workflow to decide whether L\in \mathbf{R},\mathbf{RE}\setminus\mathbf{R}, \mathbf{co}\mathbf{RE}\setminus\mathbf{R}, \dots

Given a language L we now have all the tools to show whether L\in \mathbf{R}, or L\in \mathbf{RE}\setminus\mathbf{R}, or L\in \mathbf{co}\mathbf{RE}\setminus\mathbf{R}, or L\in \Sigma^0_2\setminus (\mathbf{RE}\cup\mathbf{co}\mathbf{RE}), etc.

  • L\in \mathbf{R}
  • L\in \mathbf{RE}\setminus\mathbf{R}
  • L\in \mathbf{co}\mathbf{RE}\setminus\mathbf{R}
  • L\notin \mathbf{RE}\cup\mathbf{co}\mathbf{RE}

Usually the simplest thing is to describe a Turing machine or algorithm to decide L.

First show that L\in \mathbf{RE} either constructing a Turing machine that semi-decides L or use Theorem 26.3. Then prove that A\leq_m L for some language A\notin\mathbf{co}\mathbf{RE}, for example showing that \mathtt{K}\leq_m L.

first show that L\in \mathbf{co}\mathbf{RE} either constructing a Turing machine that semi-decides \overline L or use Theorem 26.4. Then prove that A\leq_m L for some language A\notin\mathbf{RE}, for example showing that \overline{\mathtt{K}}\leq_m L.

Prove that A\leq_m L and B\leq_m L for some A\in \mathbf{RE} and B\in \mathbf{co}\mathbf{RE}, for example K and \overline{K}.

Exercise 27.2 In this execise we continue on Exercise 26.9. Show that

  • \mathtt{FIN}=\{p:\mathscr{L}(M_p) \text{ is finite}\}\in\Sigma^0_2\setminus (\mathbf{RE}\cup\mathbf{co}\mathbf{RE}).
  • \mathtt{TOT}=\{p:M_p \text{ halts on every input}\}\in\Pi^0_2\setminus (\mathbf{RE}\cup\mathbf{co}\mathbf{RE}).

Exercise 27.3 Consider the language
A=\mathtt{K}\oplus\overline{\mathtt{K}}=\{\langle 0,z\rangle:z\in\mathtt{K}\}\cup\{\langle 1,z\rangle:z\notin\mathtt{K}\}. Show that A\in\Delta^0_2 but A\notin\mathbf{RE}\cup\mathbf{co}\mathbf{RE}.

Similarly to the exercise above, we have that for every k there exists a language L\in \Delta^0_{k+1}\setminus (\Sigma^0_k\cup\Pi^0_k).
